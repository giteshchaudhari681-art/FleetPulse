# Scope

## In Scope
Everything assigned to PRs 1–100 of the master project roadmap. This includes:
- Foundation and Engineering Contract setup
- Backend and Frontend Bootstrapping
- Authentication and RBAC
- Fleet, Vehicle, and Driver management APIs
- Python Vehicle Simulator and MQTT telemetry ingestion
- Real-Time Websocket platform for live tracking and maps
- Dashboard and Analytics (fuel, speed, temp)
- Trips and Geofencing intelligence
- Alerts and Operations Engine
- Maintenance scheduling and Audit trailing
- Observability, Security, and Production deployment readiness

## Out of Scope
Anything not included in the PR 1–100 roadmap, including but not limited to:
- Mobile native applications (iOS/Android)
- Hardware manufacturing or embedded OS for telematics devices
- Third-party SSO implementations (e.g., SAML, OAuth with Google)
- Financial billing, tax, or payroll tracking
- Turn-by-turn navigation for drivers
- Fleet routing optimization or booking algorithms

**Important:** New features or technologies will NOT be added simply because they seem useful. Scope strictly conforms to the defined PR boundaries to prevent scope creep.
